# `_mech_type`

Reads the currently selected robot type.

### Description

It cannot be set as the left side of an assignment statement.

Supported from V70.02-00

### Syntax

```python
var res
res = _mech_type
```

### Sample

```python
   ...
   # Prints the current robot type.
   print _mech_type
   ...
   end
```
