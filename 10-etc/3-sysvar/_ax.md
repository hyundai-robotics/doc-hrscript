# _ax 변수

축의 명칭으로 축의 인덱스를 읽을 때 사용합니다.

### 설명

축의 인덱스는 0을 기준값으로 얻습니다. "_ax." 이후의 문자열을 축의 명칭으로 지정하십시오. 축의 명칭은 소문자와 대문자 모두를 지원합니다.

### 문법

```python
var res
res = _ax.v # V축의 인덱스 얻기
```

### 사용 예

```python
   ...
   # R1축의 현재 위치를 출력합니다.
   global po
   po=cpo("joint")
   print po.j[_ax.R1]
   ...
   end
```
